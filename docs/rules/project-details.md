# Project Details

- Backend: Python 3.13+, FastAPI, Pydantic Settings, SQLAlchemy async, Alembic, PostgreSQL, LangChain, and LangGraph.
- Frontend: Next.js, React, TypeScript, shadcn/ui, Tailwind CSS, TanStack Query, Vitest, Testing Library, MSW, and Playwright.
- Keep all source code, comments, documentation, and generated Markdown text in English.
- Use strict TypeScript settings and meaningful type annotations in Python.
- Prefer `snake_case` for Python names, `camelCase` for TypeScript variables/functions, `PascalCase` for classes/components, and `UPPER_SNAKE_CASE` for constants.
- Preserve public contracts and existing async boundaries unless the task explicitly changes them.
- Read the relevant architecture and engineering docs before structural changes.
